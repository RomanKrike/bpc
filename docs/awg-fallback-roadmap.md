# AWG fallback roadmap

After the AWG2 baseline passes:

1. add validated CPS/I1-I5 profiles;
2. add transport-level probes;
3. combine VLESS/REALITY and AWG in a Mihomo fallback group;
4. verify connection behavior when the active RU transport fails;
5. add a third independent path such as Tailscale/DERP.
